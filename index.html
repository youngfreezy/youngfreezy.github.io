Mayo Clinic01

Less time reviewing.
More confidence publishing.

A five-agent workflow checks health articles against 34 validation rules, with a human review step before results reach an editor.

~2 hours → <10 minutesArticle review time
LangGraphGoogle ADK / A2ANext.js
Inside the build +

A router clears straightforward cases without a model call. Independent checking agents communicate over A2A; LangGraph pauses the workflow for human review. Validation rules load from a graph database with a file fallback, and RAGAS measured groundedness and coverage before rollout.

Polaris IO02

Agents with budgets.
Infrastructure with receipts.

An agent SDK and runtime with model-tier routing, schema-based escalation, cross-provider failover, and budget checks before each call.

144 evaluation runsTo select the agent framework
Python / FastAPITypeScriptAWS EKS
Inside the build +

Built client-level cost attribution, budget caps, and kill switches verified against live provider usage. Added encrypted, tenant-scoped replay of completed runs and tracing that blocks unredacted sensitive fields. The PioWorkflow evaluation framework reduced agent-skill testing cost from $4.49 to under $1 per run.

Signet Jewelers03

An AI studio.
In production in three months.

AI Foundry gives internal teams a place to build agents that search their own documents, backed by a shared Amazon Bedrock gateway.

Days → hoursPull-request review with a three-agent copilot
Amazon BedrockReactAWS
Inside the build +
